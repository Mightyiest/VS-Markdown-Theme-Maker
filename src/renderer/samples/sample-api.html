⚡ Payment Gateway v2 REST API

Official API documentation for processing secure payments, customer subscriptions, and automated webhook events.

Base URL: https://api.payments.example.com/v2
All requests require Bearer Authentication header: Authorization: Bearer sec_key_live_99823

1. Create Payment Charge

Initializes a new payment transaction for a customer order.

Endpoint Specifications

Method Path Auth Required Rate Limit
POST /charges Yes (Secret Key) 120 req / min
GET /charges/:id Yes (Publishable Key) 300 req / min

Request Payload Example

{
  "amount": 4999,
  "currency": "usd",
  "customer": "cus_99182371",
  "metadata": {
    "order_id": "ORD-2026-8819",
    "environment": "production"
  }
}

Success Response 201 Created

{
  "id": "ch_3M091823192",
  "status": "succeeded",
  "amount": 4999,
  "paid": true,
  "created_at": 1770359520
}

Error Codes & Status Badges

For troubleshooting failed charges, refer to the Error Handling Guide.

  • invalid_card — Card details failed validation
  • insufficient_funds — Card declined due to credit limits
  • rate_limit_exceeded — API threshold exceeded
