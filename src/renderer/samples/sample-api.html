⚡ Payment Gateway & Cloud API v2

Official API documentation for processing secure deployments, customer subscriptions, and automated webhook events.

Base URL: https://api.antigravity.io/v2
All requests require Bearer Authentication header: Authorization: Bearer sec_key_live_99823

1. Create Deployment Charge

Initializes a new cloud deployment transaction for a workspace cluster.

Endpoint Specifications

Method Path Auth Required Rate Limit
POST /v2/deployments Yes (Secret Key) 120 req / min
GET /v2/deployments/:id Yes (Publishable Key) 300 req / min

Request Payload Example (JSON)

{
  "project_name": "aurora-dashboard",
  "environment": "production",
  "replica_count": 4,
  "auto_scale": {
    "min": 2,
    "max": 8
  }
}

2. Rate Limiting Model & Token Bucket

The token bucket algorithm regulates burst traffic:

T(t) = min( Capacity, T(t_0) + ρ · (t - t_0) )

3. Request Flow (Mermaid Sequence)

sequenceDiagram autonumber actor Client as API Client participant Gateway as API Gateway participant Auth as Token Bucket Limiter participant Engine as Deployment Microservice Client->>Gateway: POST /v2/deployments (Bearer Key) Gateway->>Auth: Validate Token & Quota Auth->>Engine: Forward Validated Payload Engine-->>Gateway: 201 Created (Deployment URL) Gateway-->>Client: { "status": "succeeded" }

4. Error Handling & Status Codes

  • 201 Created — Deployment provisioned and operational
  • 400 Bad Request — Payload schema validation failed
  • 401 Unauthorized — Bearer token expired or invalid
  • 429 Rate Limited — Token bucket empty; backoff required
