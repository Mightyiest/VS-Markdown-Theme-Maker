🚀 Release Notes — v2.4.0 (2026-08-06)

Major release featuring popular developer theme presets, interactive sample document switchers, and binary bundle size optimizations.

Breaking Changes: Theme configuration syntax in .vscode/settings.json now automatically normalizes custom theme identifiers.

✨ New Features

  • Popular Presets Pack: Added Catppuccin, Tokyo Night, Nord, and Dracula community themes.
  • Sample Document Switcher: Easily test themes against API specs, academic papers, release notes, and READMEs.
  • Single-Instance Lock: Prevent duplicate background processes when launching from IDE terminals.

⚡ Performance Enhancements

Metric v2.3.0 v2.4.0 Improvement
Executable Size 94.8 MB 78.2 MB -17.5%
Launch Time 1.2s 0.4s 3x Faster

🐛 Bug Fixes

  • Fixed theme sorting order evaluation error on custom creation dates.
  • Fixed color swatch alignment on custom theme cards in left sidebar.
  • Resolved orphaned backup file discovery on project record deletion.
