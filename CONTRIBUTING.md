# Contributing to VS Markdown Theme Maker 🎨

Thank you for your interest in contributing to **VS Markdown Theme Maker**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

---

## 🛠️ Development Setup

1. **Fork and Clone the Repository**:
   ```bash
   git clone https://github.com/<your-username>/VS-Markdown-Theme-Maker.git
   cd VS-Markdown-Theme-Maker
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Application in Development**:
   ```bash
   npm start
   ```

4. **Run Unit Tests**:
   ```bash
   npm test
   ```
   *Make sure all tests pass before submitting a pull request.*

---

## 📥 Submitting Pull Requests (PRs)

1. Create a descriptive feature branch:
   ```bash
   git checkout -b feat/my-new-feature
   ```
2. Write clean code and preserve existing formatting.
3. Ensure `npm test` passes completely.
4. Push your branch and submit a Pull Request to `main`.
5. Clearly describe the changes made and link any relevant open issues.

---

## 🐛 Reporting Bugs & Requesting Features

- Use the official [GitHub Issues](https://github.com/Mightyiest/VS-Markdown-Theme-Maker/issues) tab.
- Provide step-by-step reproduction steps, expected vs. actual behavior, and OS/app versions.
