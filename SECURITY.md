# Security Policy

## Supported Versions

The following versions of **VS Markdown Theme Maker** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **do not** open a public issue.

Instead, please report the vulnerability privately through one of the following methods:

1. **GitHub Security Advisory**: Navigate to the [Security Tab](https://github.com/Mightyiest/VS-Markdown-Theme-Maker/security/advisories/new) and submit a private security report.
2. **Direct Contact**: Reach out via GitHub profile or repository maintainers.

### Response Timeline

- **Acknowledgement**: Within 48 hours.
- **Assessment & Fix**: Within 7 business days for critical vulnerabilities.

Thank you for helping keep **VS Markdown Theme Maker** and its community safe!
