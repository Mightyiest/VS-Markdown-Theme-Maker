⚡ Easy IDE Installation

  1. Click Download CSS for your preferred theme.
  2. Save the CSS file inside your project's .vscode/ folder.
  3. In .vscode/settings.json, add: 
    "markdown.styles": ["./.vscode/your-theme.css"]
